# 📊 Business Analytics with Power BI

Four Power BI lab experiments that take raw retail data from multiple sources through to cleaned, modelled, interactive dashboards. Each folder contains the `.pbix` file and the written report.

## Experiments

| # | Title | Business question | Files |
|---|---|---|---|
| 1 | **Importing data from multiple sources** | Sales in Excel, customers in CSV, products elsewhere — build one centralised reporting model by connecting flat files and MySQL in Power BI | [`Experiment - 1`](./Experiment%20-%201) |
| 2 | **Sales performance analysis** | Which products, categories and regions drive sales and profit? Built on the Sample Superstore dataset | [`Experiment - 2`](./Experiment%20-%202) |
| 3 | **Building a dashboard** | Turn the combined data model into a single interactive management dashboard | [`Experiment  - 3`](./Experiment%20%20-%203) |
| 4 | **Data cleaning with Power Query** | Fix missing values, duplicates and inconsistent entries in customer sales data, then build an interactive report on the clean data | [`Experiment - 4`](./Experiment%20-%204) |

## Skills demonstrated

- Connecting Excel, CSV and MySQL sources and building relationships in the data model
- Data cleaning and transformation in Power Query (types, nulls, duplicates, standardising values)
- KPI cards, slicers, drill-downs and category/region breakdowns
- Writing up findings for a business audience

## How to open

Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (Windows) and open any `.pbix` file. The PDF/Word report in each folder walks through the steps and screenshots.
